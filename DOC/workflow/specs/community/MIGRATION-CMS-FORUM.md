# Ablösung des Plugins `cms-forum`

> Release 4.2.0

- [x] Das Forum ist als abschaltbares Kernmodul `community` implementiert.
- [x] Nutzer-, Rollen-, Benachrichtigungs-, Mail-, Medien-, Such-, Papierkorb- und DSGVO-Dienste kommen aus dem Core.
- [x] Es wird kein Datenmigrator für das frühere Plugin behauptet.
- [x] Es werden keine Weiterleitungen von früheren Plugin-Adressen behauptet.

Eine Datenübernahme muss daher nicht auf dieser Spezifikation beruhen, sondern wäre ein getrennt beauftragtes Projekt mit eigener Bestandsprüfung und Transformationslogik.

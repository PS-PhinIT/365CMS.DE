# 365CMS – Projektdokumentation | Abschnitt: Beispielbericht WordPress-Import
> **Stand:** 2026-09-14 | **Version:** 3.5.0 | **Status:** Reference example | **Update:** 2026-09-14

## English

This file is an example report format for the CMS importer. It is documentation data, not a live import result. Import behavior and administration are implemented by the importer plugin under `CMS/plugins/cms-importer/`; validate generated reports against the actual import run.

## Deutsch

Diese Datei zeigt das Berichtsformat des CMS-Importers. Sie enthält keine Live-Importdaten. Importverhalten und Administration werden durch das Plugin unter `CMS/plugins/cms-importer/` implementiert; erzeugte Berichte sind immer gegen den tatsächlichen Importlauf zu prüfen.

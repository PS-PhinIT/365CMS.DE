# 365CMS – Projektdokumentation | Abschnitt: Asset – Mailer
> **Stand:** 2026-09-14 | **Version:** 3.5.0 | **Status:** Stable | **Update:** 2026-09-14

## English

Mailer assets support the runtime mail layer. Application behavior is implemented by `CMS/core/Services/MailService.php`, `CMS/core/Services/MailQueueService.php`, and the admin mail settings module. Configure delivery through the application settings; do not place credentials in this directory.

## Deutsch

Mailer-Assets unterstützen die Mail-Schicht der Runtime. Das Anwendungsverhalten wird durch `CMS/core/Services/MailService.php`, `CMS/core/Services/MailQueueService.php` und das Admin-Modul für Mail-Einstellungen implementiert. Versand über die Anwendungseinstellungen konfigurieren; Zugangsdaten gehören nicht in dieses Verzeichnis.

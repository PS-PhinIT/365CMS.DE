# 365CMS – Projektdokumentation | Abschnitt: Asset – SEO
> **Stand:** 2026-09-14 | **Version:** 3.5.0 | **Status:** Stable | **Update:** 2026-09-14

## English

The SEO asset is consumed by the CMS SEO layer. Runtime integration is provided by `CMS/core/SEOService.php`, `CMS/core/Services/SEO/SeoSchemaRenderer.php`, and the SEO admin modules. Use those application boundaries instead of calling asset internals from views.

## Deutsch

Das SEO-Asset wird von der CMS-SEO-Schicht verwendet. Die Runtime-Integration erfolgt über `CMS/core/SEOService.php`, `CMS/core/Services/SEO/SeoSchemaRenderer.php` und die SEO-Admin-Module. Verwenden Sie diese Anwendungsschnittstellen und rufen Sie keine Asset-Interna direkt aus Views auf.
